# Система записи и учета скидок клиентов


## Паттерны

### Порождающие

- Строитель (booking_service/appointment_builder.py) - собирает финальную запись клиента. Следит, чтобы клиент не списал баллов больше, чем положено.
- Фабричный метод (loyalty_service/transaction_factory.py) - создает операции с баллами (начисление/списание). Проверяет, хватает ли у клиента баланса перед списанием.

### Структурные

- Фасад (booking_service/booking_facade.py) - Вызывает один метод,берет скидку, сохраняет бронь и отправляет СМС.
- Прокси (loyalty_service/cached_rules_proxy.py) - один раз скачивает правила скидок из базы и держит их в памяти.
- Адаптер (notification_service/senders_adapter.py) - нужен для отправки сообщений. Помогает легко менять сервисы рассылок (СМС, Телеграм), ничего не ломая в нашем основном коде.

### Поведенческие

- Стратегия (loyalty_service/pricing_strategy.py) - считает, сколько клиент должен заплатить. Сейчас считает по его уровню, позже можно добавить логику для промокодов.
- Состояние (booking_service/appointment_state.py) - следит за статусами. Если услуга уже оказана, он не даст её отменить.
- Наблюдатель (loyalty_service/loyalty_observer.py, notification_service/event_listener.py) - Как только визит окончен, автоматически начисляет кэшбэк и отправляет чек клиенту.
